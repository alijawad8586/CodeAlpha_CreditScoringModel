# Credit Scoring Model

## Overview

This project predicts whether a customer is creditworthy based on historical financial information using machine learning classification algorithms.

This project was developed as part of the CodeAlpha Machine Learning Internship.

---

## Features

- Data preprocessing
- Feature engineering
- Classification models
- Model evaluation
- Performance comparison

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Machine Learning Algorithms

- Logistic Regression
- Decision Tree
- Random Forest

---

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

---

## Dataset

Financial dataset containing:

- Income
- Credit History
- Loan Amount
- Debt
- Payment History
